## 3. Конфигурация сервера

```bash
g++ -O2 -pthread server_v1.cpp -o server_v1
./server_v1 --port 8080
```

Версия: `server_v1.cpp` — по одному потоку на каждое соединение.

## 4. Сценарий нагрузки

| Параметр | Значение |
|----------|---------|
| Инструмент нагрузки | tcpkali 1.1.1 |
| Число клиентов | 100 |
| Длительность теста | 30 сек |
| Размер запроса | 256 байт |
| Команда запуска | см. ниже |

```bash
tcpkali --connections 100 --duration 30s \
        --message "$(python3 -c 'print("A"*256)')" \
        --latency-percentiles 50,95,99 \
        127.0.0.1:8080
```

## 7. Наблюдения

- При достижении 100 соединений процессор устойчиво держался выше 300%
- Пики задержки (> 200 мс) совпадали с пиками создания новых потоков по данным `perf`
- 127 ошибок — отказы соединений при превышении лимита потоков ОС
- Поведение стабильно, результат воспроизводится при повторном запуске (±3%)
