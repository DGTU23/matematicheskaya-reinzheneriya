## О чём эта методика

Студенты вузов умеют писать код, но не умеют **доказывать**, что он стал лучше.  
Работодатели ждут специалистов, которые говорят на языке измерений и цифр.

Методика **«Математическая реинженерия ИТ-систем»** закрывает этот разрыв через цикл из пяти шагов:

```
Измерить → Построить модель → Проверить модель → Улучшить → Доказать эффект
```

Студент выходит с **четырьмя артефактами**, которые можно показать работодателю:

| Артефакт | Что доказывает |
|----------|---------------|
| Паспорт системы (Model Card) | Студент понимает, что моделирует |
| Протокол эксперимента | Измерения можно повторить |
| Репозиторий с кодом | Улучшение реализовано |
| Таблица «до / после» | Эффект доказан цифрами |

## Как использовать

1. Скачайте шаблоны из папки `templates/`
2. Выберите учебный проект (сервер, сетевое приложение, база данных)
3. Заполните **Паспорт системы** — опишите, что измеряете и какова гипотеза
4. Заполните **Протокол эксперимента** — зафиксируйте baseline-метрики
5. Реализуйте улучшение, запустите повторные измерения
6. Заполните таблицу «до / после»
7. Защитите проект по **Рубрике оценивания**

Подробный сценарий — в файле [QUICKSTART.md](./QUICKSTART.md)
